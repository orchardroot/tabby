**`vendor/samsung/gt510lte`** on lineage-20.0: same blob set for `libsec-ril.so` and the `libril-qc-*` libs; recent commits (e.g. "gt5note10wifi: decommonize libbtnv.so") show this vendor tree now serves multiple retiredtab-descended devices, so gt510lte-specific RIL lines should be re-verified rather than assumed intact.

- No msm8916 device tree with *confirmed working* RIL on lineage-20+ was found in this pass; gt510lte would likely be first if the port succeeds.

## 5. What Android 13 / lineage-20 actually requires for legacy RIL

- LineageOS-UL's `android_hardware_interfaces` (lineage-20.0) compatibility matrices still list the legacy HIDL radio HAL as **optional**, not removed: matrix 3 — `<hal format="hidl" optional="true"><name>android.hardware.radio</name><version>1.0-3</version>...`; matrix 4 — same HAL `<version>1.4</version>`; matrix 5 — `<version>1.4</version><version>1.5</version>`. So Android 13 does **not** force a minimum radio HAL 1.4 — 1.0 (as declared in gt510lte's `target-level="legacy"` manifest) is still an accepted, optional entry.
- `hardware/ril` (LineageOS-UL fork, lineage-20.0) still ships the classic `libril`/`librilutils`/`rild`/`reference-ril` tree, not `ril-caf`. Key gate in `libril/Android.mk`: `ifneq ($(BOARD_PROVIDES_LIBRIL),true)` — setting `BOARD_PROVIDES_LIBRIL := true` (as gte-common does) tells AOSP **not** to build its own `libril`, assuming the vendor/SoC ships an equivalent. `rild/rild.rc` defines `service vendor.ril-daemon /vendor/bin/hw/rild` (class main, user radio) — the primary single-SIM rild service; `rild/Android.mk` picks `rild.rc` vs `rild.legacy.rc` based on `PRODUCT_COMPATIBLE_PROPERTY`.
- No `TARGET_USES_QCOM_BSP`/`USE_DEVICE_SPECIFIC_RIL`-style flag changed meaning between branches — both trees set `TARGET_USES_QCOM_BSP := true` and `USE_DEVICE_SPECIFIC_QCOM_PROPRIETARY := true` identically in `msm8916-common/BoardConfigCommon.mk`.
- No dedicated "LineageOS-UL wiki" turned up; closest authoritative sources are retiredtab's `LineageOS-build-manifests` instructions and the LineageOS-UL GitHub org itself, both used above in place of a wiki citation.
